# Baafiye - Missing Persons Reporting & Tracking System

Baafiye is a smart and community-focused mobile application designed to help people quickly report missing persons, share alerts, and track found-person reports in real time. The app is built to support families, friends, and local communities in responding faster during emergencies and helping reunite loved ones with their families.

## Overview

Baafiye provides a simple and modern platform for reporting missing individuals, submitting found-person reports, and receiving important safety alerts. It combines mobile reporting, location-based information, push notifications, and a backend management system to make the reporting process faster, more organized, and more reliable.

## What this app does

The application allows users to:

- Report a missing person with personal details, last-known location, date, and supporting information
- Report a found person and share relevant details for identification
- Submit community safety alerts to notify nearby users
- Track their own reports and view status updates
- Receive push notifications for new alerts, report changes, and important updates
- Use location-aware features to improve response and coordination
- Access a dashboard for managing reports and monitoring system activity

## Key features

- User-friendly mobile interface built with Flutter
- Secure authentication and user session handling
- Real-time notifications using Firebase Cloud Messaging
- Location-based updates and device location tracking
- Photo-based report support and detailed report forms
- Admin-friendly report management and verification flow
- Backend services for alerts, reports, tips, and user management

## Why this app matters

When a person goes missing, every minute matters. Baafiye helps reduce delays by giving the public a fast way to report incidents, share information, and stay informed. It encourages community participation and improves coordination between individuals, responders, and administrators.

## Technology stack

- Frontend: Flutter
- Backend: Node.js with Express
- Database/API integration: RESTful services
- Notifications: Firebase Messaging and local notifications
- Location services: Geolocator and map-based support

## Project structure

- Mobile app: app_flutter/
- Backend services: backendmpts/
- Images and assets: img/

## Ideal use case

Baafiye is ideal for community safety programs, local emergency response teams, family support groups, and organizations that want a digital solution for missing-person reporting and public awareness.

## Summary

Baafiye is more than just a reporting app. It is a digital safety and response platform that helps communities act quickly, share information responsibly, and support missing-person cases with greater visibility and coordination.
